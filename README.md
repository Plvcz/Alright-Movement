# Alright Movement Documentation Website

A responsive static documentation website for the Alright Movement Roblox animation plugin.

## Features

- Purple gradient hero with a centered logo
- Responsive documentation navigation
- Live section search (`/` focuses search; `Esc` clears it)
- Topic sections for keyframes, playback, onion skin, audio, events, projects, exporting, themes, and troubleshooting
- AI transparency disclaimer with the requested wording
- No build step or external dependencies

## Preview locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload the contents of this folder to the repository root (make sure `index.html` is at the root).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/(root)`, then save.
6. Wait for GitHub Pages to publish the site. The public URL will appear in the Pages settings.

## Customize

- Edit documentation copy in `index.html`.
- Adjust colors, spacing, and layout in `styles.css`.
- Change search and active-navigation behavior in `script.js`.
- Replace `assets/logo.svg` with your own logo if you have an official image.
