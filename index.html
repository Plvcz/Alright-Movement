✦ THE USER GUIDE

Make every frame count.

Alright Movement is an animation editing workflow for building keyframe-based motion, previewing timing, and exporting playback code for your Roblox experience.

01 / BASICS

The interface

The editor brings the animation timeline and its editing controls into one workspace. The timeline is where you organize tracks, place keyframes, and review how values change over time.

✦

Tip Get comfortable with the timeline before building a long animation. A small, well-organized sequence is easier to revise.

02 / EDITING

Keyframes & easing

Keyframes define values at specific points in the animation. The playback system evaluates the values between keyframes to create motion.

  • ✓Place keyframes intentionallyUse them where a value or movement should change.
  • ✓Review timingSpacing between keyframes affects the pace of the animation.
  • ✓Choose easing deliberatelyEasing changes how motion accelerates or decelerates between points.
03 / PREVIEW

Playback & preview

Preview your animation regularly instead of waiting until the timeline is complete. Check the start, middle, and end of the sequence for unexpected jumps or timing issues.

04 / PRECISION

Onion skin

Onion skin helps you compare nearby poses by showing surrounding animation frames as visual references. Use it to judge spacing, direction, and consistency between poses.

  • Use nearby frames as a guide while adjusting a pose.
  • Look for uneven spacing or sudden changes in direction.
  • Turn it off when the extra visual information makes the current pose harder to read.
05 / SOUND

Audio clips

Audio clips can play alongside an animation. Add a supported audio asset, place it at the intended point in the timeline, and preview the sequence to check synchronization.

  1. Add an audio asset using a supported Roblox audio asset ID or local Studio audio file.
  2. Position the clip at the desired point in the animation.
  3. Preview playback and adjust timing as needed.
!

Audio not playing? Check that the asset is available to the experience, permissions are correct, and the asset has finished loading. Local file references may be temporary.

06 / TIMELINE ACTIONS

Animation events

Animation events mark points in the timeline where runtime code can trigger a registered action.

  1. Add an event marker and place it at the intended time.
  2. Set the event name expected by your runtime setup.
  3. Register a handler for that event before playback reaches it.
  4. Preview the animation and confirm the handler fires at the right time.
ⓘ

Remember An event marker does not execute arbitrary code by itself. The runtime must register a matching handler.

07 / PROJECTS

Saving projects

Save regularly to preserve your work and make it easier to return to an earlier version.

  • Give each project a recognizable name.
  • Save after significant keyframe or timeline changes.
  • Reopen saved work when practical to verify the project is intact.
  • Keep separate versions before major revisions.

Project data may include settings such as frame rate, duration, looping, tracks, and keyframes.

08 / RUNTIME

Exporting an animation

Exporting generates Luau code intended to play the animation outside the editor.

  1. Review the timeline, keyframes, duration, frame rate, and loop settings.
  2. Use the export controls to generate the runtime module or script.
  3. Place the generated code in an appropriate location for your experience.
  4. Read the generated module's setup instructions and exact method signatures.
  5. Test playback in a separate play session.

Do not guess method signatures. Use the generated module's actual API and initialization requirements. Keep editor-only code separate from runtime logic, and validate client input on the server whenever it affects authoritative gameplay state.

09 / PERSONALIZATION

Customizing the theme

Use the theme settings to personalize the editor's appearance. Available options can include accent, background, panel, separator, and title-bar colors, plus a background image.

  1. Open the theme settings.
  2. Adjust the colors or background image.
  3. Apply the changes and check text contrast throughout the interface.
10 / HELP

Troubleshooting

The animation does not play

Confirm that keyframes exist, the correct project is selected, and the playback position and duration are valid. Check the output for errors.

Keyframes behave unexpectedly

Check the target track, keyframe positions, values, and easing settings. Preview the sequence after making changes.

Audio does not play

Verify the asset ID, permissions, availability, and loading state. Test the audio independently if needed.

Events do not trigger

Check the marker's position and name, and ensure a matching handler is registered before playback reaches it.

The exported animation fails

Check the generated module's setup requirements, dependencies, and exact method signatures. Test in a clean play session and inspect runtime errors.
